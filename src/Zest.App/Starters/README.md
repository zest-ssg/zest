# Zest Starter

A minimal single-article blog scaffold generated by `zest init`.

## Layout

```
.
├── _config.toml          # site metadata and build options
├── _themes/oxygen/       # self-contained theme
│   ├── _theme.toml       # theme manifest
│   ├── _layouts/         # post.html (article layout)
│   ├── _includes/        # head.html, header.html
│   └── assets/css/       # main.zcss (single stylesheet)
└── content/
    ├── index.md          # the article (rendered at /)
    ├── rss.zest.fsx      # RSS 2.0 feed
    ├── atom.zest.fsx     # Atom 1.0 feed
    └── sitemap.zest.fsx  # XML sitemap
```

## How it works

- The article is a Markdown file with `+++` TOML front matter. Its file name,
  `index.md`, maps it to the site root `/`.
- The `post` layout renders the article title, author, date, and body.
- Styles are written in ZCSS (`main.zcss`), a CSS superset compiled to plain
  CSS at build time.
- The feeds and sitemap are `.zest.fsx` pages built with `Zest.Dsl.DslXml`.

## Workflow

```bash
zest init my-blog     # scaffold this starter
cd my-blog
zest serve            # dev server with live reload
zest build            # static output into _site/
```

## Commands

| Command        | Description                            |
|----------------|----------------------------------------|
| `zest init`    | Scaffold a new site from this starter  |
| `zest build`   | Build the site into `_site/`           |
| `zest serve`   | Run the dev server with live reload    |
| `zest clean`   | Remove build output                    |
