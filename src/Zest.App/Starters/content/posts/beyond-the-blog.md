This starter is a full blog system, not just a list of posts:

- **Pagination** — `/posts/` is generated by the engine's pagination
  generator; add `<!-- @paginate posts, 5 -->` to any listing and it
  takes over that URL, producing `/posts/page/2/` and friends
- **Tag archives** — write a tag in a post's front matter and
  `/tags/<term>/` is generated automatically
- **Tag cloud** — the `/tags/` index is an F# DSL page built with
  `DslCollections.tag_cloud`
- **Yearly archives** — `/archives/` groups posts by year with a plain
  `Array.groupBy`
- **Static search** — `/search/` embeds a JSON index at build time and
  filters it in the browser
- **Feeds** — RSS 2.0 and Atom 1.0 are generated by `DslXml` into
  `/rss.xml` and `/atom.xml`

Everything is content-driven: add a file, rebuild, and the site grows.
